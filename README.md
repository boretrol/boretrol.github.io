README for github hosted website boretrol.github.io

The initial purpose of this website is to make available online in
searchable form the tweets from my (boretrol)'s Twitter archive.  In early
2026, X changed the formerly very useful searching to use a different
syntax, breaking what I had been using, and made it so it only returns a
small number of tweets and more often than not finds nothing.  Fortunately
the also very useful Twitter archive search functionality remains untouched
(so far).
